# Web

The Elsewise UI: a React 19 + TanStack Router SPA on Vite 8 and Tailwind v4. Runs standalone on `:3000` and doubles as
the desktop's renderer, which loads the dev server, or the `build:electron` output in production.

Run pnpm from the **repo root**: `pnpm --filter @elsewise/web <script>`.

## Layout

| Path                   | What it is                                                                        |
|------------------------|-----------------------------------------------------------------------------------|
| `src/main.tsx`         | Entry point; mounts the router into `#app`.                                       |
| `src/router.tsx`       | The router. The `electron` build uses hash history, since file:// has no routing. |
| `src/routes/`          | File routes. `__root.tsx` is the shell.                                           |
| `src/routeTree.gen.ts` | Generated by the TanStack Router Vite plugin on `dev`/`build`, and committed.     |
| `src/styles.css`       | Imports `@elsewise/components/styles.css`, the design system's Tailwind entry.    |

## Rules

- **Use `@/`** to reach `src/`.
- **The embedder through `window.bridge`.** Types come from `@elsewise/bridge`; every surface may be undefined, as in
  a plain browser.
- **Never hand-edit `routeTree.gen.ts`.**
- **Comments**: `//` for comments, `/** … */` for doc comments. Wrap prose at 120 columns by hand.
