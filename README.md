# Elsewise

A cross-platform **agentic development environment (ADE)**.

## Prerequisites

- **Node** (v26 recommended) and **pnpm**
- **Flutter** (≥ 3.47.0) for the `tools/icons` CLI.

## Getting started

Everything runs from the repo root — the pnpm workspace and dart are both wired through
the `Makefile`.

```bash
make bootstrap    # pnpm install + dart pub get, then generate
make dev          # web dev server (:3000) + Electron window, together
```

`make help` lists every target (`build`, `lint`, `test`, `generate`, …); each has a short
alias (`b`, `l`, `t`, `g`).

### Building & packaging

```bash
make build        # build the web UI (Electron mode) + the desktop bundle
pnpm dist:mac     # .app + dmg   (also: dist:win, dist:linux)
```

### Daemon

The daemon is a Node project in the pnpm workspace (`daemon/`).

```bash
pnpm --filter daemon dev      # also: build, test
```

## Conventions

- **Package manager:** pnpm only, workspace rooted at the repo root. Settings live in
  `pnpm-workspace.yaml` (not `.npmrc`).
- **Web formatting/linting:** [Biome](https://biomejs.dev) — `pnpm --filter web check --write`.
- **Protobuf:** `apps/web` owns generation — `pnpm --filter web generate` (also runs on
  install) emits `proto/` into the gitignored `apps/web/src/gen/`.
- **Routes:** `apps/web/src/routeTree.gen.ts` is generated by TanStack Router
  (`pnpm --filter web generate-routes`) — don't hand-edit it.

See [`AGENTS.md`](./AGENTS.md) for a compact orientation and [`DESIGN.md`](./DESIGN.md)
for the design system.
